# 📖 About

**Persian Learning ChatBot** is a modern browser-based Persian chatbot designed for learning, education, and intelligent conversations.

Unlike simple static chatbots, this project is capable of remembering learned responses using the browser's LocalStorage, allowing it to gradually improve through user interactions. The chatbot works entirely on the client side and requires no server, database, or external AI API.

Its clean interface, adaptive learning system, and persistent local memory make it an excellent educational project for learning JavaScript, chatbot design, and browser storage concepts.
