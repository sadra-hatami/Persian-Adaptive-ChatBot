# 📖 About

**Persian Learning ChatBot** is an AI-powered web application designed to help users learn the Persian (Farsi) language through natural conversations.

Instead of using traditional lessons alone, learners can interact with an intelligent chatbot to practice vocabulary, improve grammar, ask questions, and gain confidence in reading and writing Persian.

The application provides an intuitive chat interface, making Persian learning engaging, interactive, and accessible from any modern web browser.
